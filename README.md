# My Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and professional design with smooth animations
- **Smooth Scrolling**: Navigation with smooth scroll behavior
- **Contact Form**: Functional contact form for inquiries
- **Projects Showcase**: Display your projects with images and descriptions
- **Skills Section**: Highlight your technical skills
- **Mobile Friendly**: Optimized for mobile, tablet, and desktop views

## Project Structure


## Sections

1. **Navigation Bar**: Sticky navigation with links to all sections
2. **Hero Section**: Eye-catching introduction with call-to-action
3. **About Section**: Brief introduction about yourself
4. **Projects Section**: Showcase of your work
5. **Skills Section**: List of technical skills
6. **Contact Section**: Contact form for visitors
7. **Footer**: Social links and copyright

## Customization

### Update Personal Information
Edit `index.html` to update:
- Your name and title in the hero section
- About section content
- Project details and links
- Skills list
- Contact form

### Change Colors
Edit `css/styles.css`:
- Modify the CSS custom properties in `:root`
- Change `--primary-color`, `--secondary-color`, etc.

### Add Projects
1. Add project images to `assets/images/`
2. Duplicate a `.project-card` div in `index.html`
3. Update image src, title, description, and link

### Add Functionality
Extend `js/main.js` to add:
- Form validation
- Blog functionality
- Dark mode toggle
- Portfolio filtering

## Getting Started
